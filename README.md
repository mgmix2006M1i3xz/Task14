Условие задачи:
Реализуйте в виде отдельной функции <type> function(double *ptr_array, int n, ...) обработку одномерного массива. Функция должна принимать указатель на массив, его размер и необходимые параметры, а также возвращать найденное значение.

Задание по варианту 16:
Определение первого порядкового номера элемента, не равного заданному значению A.

Указание:

Функция должна вернуть индекс найденного элемента (если он есть), либо -1, если все элементы массива равны A.

Реализуйте использование созданной функции в main() с выводом результата.

- Цикл i от 0 до n-1.

- Если array[i] != A: вернуть i.

- Если цикл завершился: вернуть -1.

2. Реализация программы

#include <stdio.h>
#include <locale.h>

// Функция поиска первого элемента, не равного A
int find_first_not_equal(double *ptr_array, int n, double A) {
    for (int i = 0; i < n; i++) {
        if (ptr_array[i] != A) {
            return i; // Возвращаем порядковый номер (индекс)
        }
    }
    return -1; // Если все элементы равны A
}

int main() {

    setlocale(LC_ALL, "RUS");
    int size;
    double A;

    printf("Введите размер массива: ");
    scanf("%d", &size);
    
    // Используем VLA (массив переменной длины), поддерживается в C99
    double array[size];

    printf("Введите элементы массива:\n");
    for (int i = 0; i < size; i++) {
        scanf("%lf", &array[i]);
    }

    printf("Введите значение A: ");
    scanf("%lf", &A);

    int result = find_first_not_equal(array, size, A);

    if (result != -1) {
        printf("Первый элемент, не равный %.2lf, находится на позиции %d (индекс).\n", A, result);
    } else {
        printf("Все элементы массива равны %.2lf.\n", A);
    }

    return 0;
}
